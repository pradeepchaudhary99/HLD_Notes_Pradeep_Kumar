Practice Questions

Full worked HLD write-ups — the kind of end-to-end answer you'd actually want to give in a 45-minute interview. Each one runs through the whole framework from the approach note: requirements, estimation, API, architecture, deep dives, trade-offs, failure handling, and interviewer cross-questions to quiz yourself with.

  • URL ShortenerBitly-style link shortener — key pool generation, cache-aside at scale, polyglot persistence, 19K QPS redirect path→
  • Movie / Event Ticketing PlatformBookMyShow/Ticketmaster-style booking system — seat locking under contention, overselling prevention, flash-sale traffic→
How to use these
Cover the answer, give yourself 45 minutes, and write your own version first — using the 6-step framework from Week 1. Then open the full write-up and compare: what did you miss, what would you have gotten wrong under interviewer cross-questioning, and which trade-offs did you not think to name out loud.
